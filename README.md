# Agentic ML Chatbot

An agentic AI chatbot built with Python, FastAPI, Gemini, and machine learning.

The system uses a custom Python agent that decides which action to take based on the user's request. It can answer general questions, perform mathematical calculations, and use a machine learning model to predict house prices.

The project demonstrates an agent → tool → observation → response workflow without relying on an agent framework such as LangChain.

## Features

- Custom Python-based AI agent
- Gemini-powered reasoning and response generation
- Tool selection based on user intent
- Mathematical calculations using a dedicated calculator tool
- House price prediction using a trained Random Forest model
- Conversation memory
- New Chat functionality with memory reset
- FastAPI backend
- Interactive web-based chat interface
- Safe expression evaluation for calculator operations
- Agent loop for tool execution and follow-up decisions

## Machine Learning Model

The chatbot includes a house price prediction tool built using the California Housing dataset from Scikit-learn.

### Dataset Features

The model uses 8 input features:

1. MedInc
2. HouseAge
3. AveRooms
4. AveBedrms
5. Population
6. AveOccup
7. Latitude
8. Longitude

### Model Training

Two regression models were evaluated:

- Linear Regression
- Random Forest Regressor

The Random Forest model was selected for the prediction tool based on the evaluation results.

### Random Forest Performance

- MAE: 0.328
- RMSE: 0.506
- R² Score: 0.805

The trained model is saved locally as `models/house_price_model.pkl`.

The model file is excluded from the GitHub repository because of its large file size. It can be regenerated by running:

```bash
python models/train_model.py

## Agent Workflow

The chatbot follows an iterative agent workflow:

1. The user sends a message.
2. FastAPI receives the request.
3. The Python agent analyzes the request.
4. Gemini determines the appropriate action.
5. The selected Python tool is executed.
6. The agent receives the tool result.
7. The agent decides whether another action is required.
8. The final response is returned to the user.

For example, for a calculation:

```text
User: What is 125 × 16?
        ↓
Agent
        ↓
Gemini selects Calculator
        ↓
Calculator executes 125 × 16
        ↓
Result: 2000
        ↓
Agent generates final response
        ↓
User: 125 × 16 is 2000.
